## Contents by Category

### BER (`ber/`)
- **Plots:** AWGN vs Multipath, 500 vs 5000 symbols (Monte Carlo convergence), ZF vs MMSE comparison
- **Tables:** BER by SNR for all scenarios (AWGN, Multipath no eq, ZF, MMSE) in CSV, MD, and TXT formats
- **Generated by:** `py simulations/plot_ber_comparison.py`

### EVM (`evm/`)
- **Plots:** AWGN vs Multipath, ZF vs MMSE comparison, all scenarios (single plot)
- **Tables:** EVM (%) by SNR for all scenarios in CSV and MD formats
- **Generated by:** `py simulations/plot_evm_comparison.py`

### Constellation (`constellation/`)
- **Plots:** 4×3 grid (AWGN, Multipath no eq, ZF, MMSE × 0/10/20 dB) for QPSK and 16-QAM
- **Generated by:** `py simulations/plot_constellation_comparison.py`

### Pilots (`pilots/`)
- **Channel estimation accuracy:** True H vs Estimated H (magnitude, phase, MSE per subcarrier, error distribution)
- **BER comparison:** Known channel vs Pilot-based estimation
- **EVM comparison:** Known channel vs Pilot-based estimation
- **Constellation comparison:** Known channel vs Pilot-based estimation
- **Generated by:** `py simulations/plot_pilots_comparison.py --symbols 5000 --equalize zf|mmse`

### Documentation (`docs/`)
- **simulation_summary.md:** High-level summary of results and conclusions
- **README.txt:** Brief overview of summary contents
- **RUN_COMPARISON.txt:** Instructions for regenerating summary outputs

## Per-Run Outputs

Individual simulation runs are stored in `results/<run_dir>/`:
- `results/<N>_symbols/` — AWGN channel
- `results/<N>_symbols_multipath/` — Multipath, no equalizer
- `results/<N>_symbols_multipath_zf/` — Multipath with ZF equalizer
- `results/<N>_symbols_multipath_mmse/` — Multipath with MMSE equalizer
- `results/<N>_symbols_multipath_zf_pilots/` — Multipath with ZF + pilots
- `results/<N>_symbols_multipath_mmse_pilots/` — Multipath with MMSE + pilots

Each run directory contains:
- `images/` — BER, EVM, constellation plots, channel response (multipath)
- `ber_vs_snr_*.csv` — BER data
- `evm_vs_snr_*.csv` — EVM data

## Regenerating Summary Outputs

**After running base simulations:**
```powershell
py simulations/plot_ber_comparison.py
py simulations/plot_evm_comparison.py
py simulations/plot_constellation_comparison.py
py simulations/plot_pilots_comparison.py --symbols 5000 --equalize zf
py simulations/plot_pilots_comparison.py --symbols 5000 --equalize mmse
```

**To organize existing files** (if you have old files in `summary/` root):
```powershell
py results/summary/ORGANIZE_EXISTING.py
```
