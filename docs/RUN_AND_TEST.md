# Running simulations and tests

## Simulations

**Default (AWGN):**
```
py run_simulation.py
```

**Multipath — 500 symbols (quick run):**
```
py run_simulation.py --channel multipath --symbols 500
```

**5000 symbols (full run):**
```
py run_simulation.py --channel multipath --symbols 5000
```

**Multipath with MMSE:**
```
py run_simulation.py --channel multipath --equalize mmse --symbols 500
```

**Multipath without equalizer (for comparison table):**
```
py run_simulation.py --channel multipath --equalize none --symbols 5000
```

## Running tests

**From project root:**
```
py -m pytest tests/ -v
```

**With full traceback:**
```
py -m pytest tests/ -v --tb=long
```

**With coverage:**
```powershell
py -m pip install pytest-cov
py -m pytest tests/ -v --cov=src --cov-report=term-missing
```

## Comparison plots (after running simulations)

To generate summary plots in `results/summary/` (AWGN vs Multipath, 500 vs 5000, ZF vs MMSE):

```powershell
py simulations/plot_ber_comparison.py
py simulations/plot_ber_comparison.py --symbols 500
```

**EVM comparison (EVM vs SNR by scenario, ZF vs MMSE, all scenarios):**
```
py simulations/plot_evm_comparison.py
py simulations/plot_evm_comparison.py --symbols 5000
```

## Comparison table and constellation

**BER table by scenario (AWGN, Multipath no eq, ZF, MMSE)** — generated by:
```
py simulations/plot_ber_comparison.py
```

**EVM table by scenario** — generated by:
```
py simulations/plot_evm_comparison.py
```

**Constellation comparison: 4 columns (AWGN, Multipath no eq, ZF, MMSE) × 3 rows (0, 10, 20 dB):**
```
py simulations/plot_constellation_comparison.py
py simulations/plot_constellation_comparison.py --symbols 100
```
